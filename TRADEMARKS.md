- **Run unmodified usertrust and show its mark.** `usertrust-ui` displays the usertrust logo in its header. You may ship and run the unmodified package, mark included.

- **Forks and modified versions must remove the mark and be renamed.** If you distribute a fork or a modified version of usertrust, delete `packages/ui/brand/` (and the code that displays the mark), and give your version a name that is not "usertrust" and not confusingly similar to it.
